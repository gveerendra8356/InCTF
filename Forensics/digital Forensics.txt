                    InCTF FORENSICS COMMAND CHEAT SHEET

--------------------------------------------------------------------------------
1. BINWALK (Firmware, Archives & File Carving)
--------------------------------------------------------------------------------
# Scan a binary file for embedded signatures/offsets:
binwalk challenge.bin

# Extract ALL embedded files automatically:
binwalk -e challenge.bin

# Extract recursively (scans extracted files for deeper embedded files):
binwalk -M -e challenge.bin

# Generate an entropy graph (useful to detect encrypted/compressed regions):
binwalk -E challenge.bin


--------------------------------------------------------------------------------
2. ZSTEG (PNG & BMP LSB Steganography)
--------------------------------------------------------------------------------
# Run quick automated scan across all channels and bit planes:
zsteg -a image.png

# Extract specific bit plane (e.g., Red channel 1st bit):
zsteg -E "r1,lsb,lsbXY" image.png > extracted_payload.bin

# Extract payload using all channels LSB in row-order:
zsteg -E "b1,msb,lsb" image.png > output.txt


--------------------------------------------------------------------------------
3. JSTEG (JPEG LSB Steganography)
--------------------------------------------------------------------------------
# Reveal hidden data inside a JPEG image:
jsteg reveal image.jpg output.txt

# Hide data in a JPEG image:
jsteg hide cover.jpg secret.txt output.jpg


--------------------------------------------------------------------------------
4. STEGSNOW (Text Whitespace Steganography)
--------------------------------------------------------------------------------
# View invisible trailing characters in terminal:
cat -A file.txt

# Extract hidden message (without password):
stegsnow -C file.txt

# Extract hidden message with password:
stegsnow -C -p "password123" file.txt


--------------------------------------------------------------------------------
5. STEGHIDE (JPEG, BMP, WAV, AU Steganography)
--------------------------------------------------------------------------------
# Inspect image metadata for hidden embedded payload:
steghide info image.jpg

# Extract payload with empty passphrase (hit Enter when prompted):
steghide extract -sf image.jpg -p ""

# Extract payload using a known passphrase:
steghide extract -sf image.jpg -p "password"


--------------------------------------------------------------------------------
6. EXIFTOOL (File Metadata & Tag Inspection)
--------------------------------------------------------------------------------
# View all metadata properties of any file:
exiftool file.jpg

# Filter specifically for comment, artist, software, or flag tags:
exiftool file.jpg | grep -iE "comment|artist|user|software|description|flag"


--------------------------------------------------------------------------------
7. STEGSOLVE (Java GUI Bit-Plane Viewer)
--------------------------------------------------------------------------------
# Run Stegsolve GUI:
java -jar stegsolve.jar

# Key Workflows:
# - File -> Open -> Select target PNG/BMP
# - Use Arrow Keys to cycle through Red/Green/Blue Planes 0-7 & Inverted Colors
# - Analyse -> Data Extract (Manually pull LSB streams)
# - Analyse -> Frame Browser (Inspect individual GIF frames)


--------------------------------------------------------------------------------
8. TERMINAL ONE-LINERS & STRING TRICKS
--------------------------------------------------------------------------------
# 1. Base64 Decode:
echo "SW5DVEZ7ZmxhZ19oZXJlfQ==" | base64 -d

# 2. Hex to ASCII Conversion:
echo "496e4354467b666c61677d" | xxd -r -p

# 3. ROT13 / Caesar Cipher Decoding:
echo "VnPGS{synt_urert}" | tr 'A-Za-z' 'N-ZA-Mn-za-m'

# 4. Search strings for Flag formats (Min string length: 8):
strings -n 8 challenge.raw | grep -iE "inctf|flag|\{"

# 5. Reverse a string (for inverted flags):
echo "}g2ls_2s41c_sI_sI3hT{FTCnI" | rev

# 6. View Hex dump of a file header (first 32 bytes):
head -c 32 file.png | xxd


--------------------------------------------------------------------------------
9. PDF FORENSICS (pdf-parser & pdfid)
--------------------------------------------------------------------------------
# Quick overview of suspicious PDF objects (JS, Embedded Files):
pdfid challenge.pdf

# Search PDF for specific keywords/objects:
pdf-parser -s flag challenge.pdf

# Extract and decompress a raw stream from object 5:
pdf-parser -o 5 -d extracted_stream.bin challenge.pdf


--------------------------------------------------------------------------------
10. NETWORK PCAP TRIAGE (Tshark CLI)
--------------------------------------------------------------------------------
# List all HTTP GET/POST requests and DNS queries:
tshark -r capture.pcap -Y "http.request or dns" -T fields -e http.host -e http.request.uri -e dns.qry.name

# Automatically export all files transferred over HTTP:
tshark -r capture.pcap --export-objects "http,extracted_files_dir"
