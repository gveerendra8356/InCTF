--------------------------------------------------------------------------------
3. OPENSSL COMMANDS (Certificates & Key Inspection)
--------------------------------------------------------------------------------
# Extract RSA public key parameters (n, e) from .pem file:
openssl rsa -pubin -in pubkey.pem -text -noout

# Extract RSA private key parameters (d, p, q) from .pem file:
openssl rsa -in private.pem -text -noout

# Decrypt raw data using private RSA key:
openssl pkeyutl -decrypt -inkey private.pem -in ciphertext.bin -out flag.txt

--------------------------------------------------------------------------------
4. AES / DES DECRYPTION VIA OPENSSL
--------------------------------------------------------------------------------
# Decrypt AES-128-CBC with key and IV in hex:
openssl enc -d -aes-128-cbc -in cipher.bin -out flag.txt -K <HEX_KEY> -iv <HEX_IV>

# Decrypt AES-256-ECB:
openssl enc -d -aes-256-ecb -in cipher.bin -out flag.txt -K <HEX_KEY>
